# NovaTech

Petit site web vitrine pour l'entreprise fictive **NovaTech**, réalisé dans le
cadre du TP final de Git.

## Pages prévues

- **Accueil** (`index.html`) — présentation de l'entreprise
- **Services** — les services proposés par NovaTech
- **Contact** — formulaire de contact

## Technologies

- HTML
- CSS (dossier `asset/`)

## Suivi du projet

Le projet est versionné avec Git : chaque évolution fait l'objet d'un commit
avec un message explicite.
